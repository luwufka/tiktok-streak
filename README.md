### ❓ Что это такое?
Это скрипт, который растет огонька за вас.  
- Работает через Selenium.  
- Использует для авторизации cookie.

### 📋 Что требуется?
- Python 3.8+
- Cookie от аккаунта

### 🚀 Запуск
**1. 🔗 Клонируйте репозиторий:**  
```bash
git clone https://github.com/luwufka/tiktok-auto-streak/
```

**2. ⚙️ Настройте окружение:**  
- `NO_GUI = true` - скрыть окно Selenium
- `TRIGGER_TIME = "18:33"` - время для запуска рассылки сообщений.
- `PROXY = "127.0.0.1:2080"` - прокси.
- `LOG_LEVEL = "TRACE"` - уровень логирования.

**3. 🍪 Настройте cookie:**  
Используйте файл: `./json/cookies.json`.

**4. 👥 Параметры рассылки:**  
Используйте файл: `./json/friends.json`.
```json
[
    {
        "username": "@user123",
        "message": "hello from script!!11"
    }
]
```

**5. ⭐ Установите модули:**
```bash
pip install -r requirements.txt
```

**6. 🚀 Запустите бота:**
```bash
python .
```

Также есть и `Dockerfile`, но работа в **Docker** тем более не тестировалась.
